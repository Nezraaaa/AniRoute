# Deck fonts

The deck uses **Outfit** (titles) and **DM Sans** (text), the same fonts as the AniRoute app.
Canva has both built in, so nothing to do there. To present from PowerPoint on a laptop, select all six
`.ttf` files, right-click, and choose **Install for all users**. Both fonts are open source under the SIL
Open Font License, from Google Fonts.
